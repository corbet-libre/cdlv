# Agent instructions

Keep Delivery within README Scope. Use maintained upstream crypto/storage/network
and actual owner capabilities; never mock domain success. Persist before ACK or
output, retain uncertain outcomes, use complete Mesh messages and existing Records.
No operator mailbox or duplicate framing/identity/accounting logic.

No local Cargo, even fmt/metadata. Use bounded public CI for native and
actual browser vectors, strict Clippy and 100% reachable line+branch coverage.
No lowered thresholds or undocumented exclusions. Heavy churn/load uses Crow.
First-party dependencies follow main with one revision per crate in Cargo.lock.

Stage explicit paths, small plain-English commits, pull --rebase before main
pushes. Never force push, publish registries, expose secrets or add AI attribution.

Current working rules (2026-10-12): the live line is branch v01 and CI is Crow through `ci-job` (never GitHub Actions); first-party dependencies follow v01. Punishment and the public record belong to the MVP and the alpha (decisions of 2026-10-02 and 2026-10-11); they gate release as the Waves proposal defines.
